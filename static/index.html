เกี่ยวกับ thscan

thscan เป็นเครื่องมือตรวจหาช่องโหว่แบบ ไม่ทำลายระบบ สำหรับหน่วยงานรัฐไทยและทีม CERT/CSIRT โดยเน้นช่องโหว่ PHP2Shell (CVE-2026-109618, CVE-2026-109619 · CVSS 9.2)

หลักการทำงาน

  • ขยายช่วง IP ที่ผู้ใช้กำหนด → ทำ reverse DNS (PTR) เหมือน nslookup -x
  • เก็บเฉพาะ host ที่เป็นโดเมนหน่วยงานไทยตามขอบเขตที่เลือก
  • ตรวจพอร์ตเว็บ แล้วอ่าน header/หน้าเพจเพื่อดูเวอร์ชัน PHP และ CMS
  • เทียบเวอร์ชันกับรุ่นที่แพตช์แล้ว (8.5.12 / 8.4.27 / 8.3.36 / 8.2.35)

ทำไม false positive ต่ำ

ใช้การเทียบเวอร์ชันเป็นหลัก ไม่ยิง exploit จริง ทุก finding มีระดับความเชื่อมั่น (confidence) ให้กรองได้ และระบุหลักฐาน (evidence) ที่ตรวจพบอย่างชัดเจน

สิ่งที่เครื่องมือนี้ไม่ทำ

ไม่ส่ง payload โจมตี ไม่ drop shell ไม่ brute-force ไม่พยายามล็อกอิน — เป็นการตรวจจับเชิงป้องกันล้วน ๆ

การนำไปใช้ (open-source / self-host)

โครงการนี้เผยแพร่เป็น open-source ให้แต่ละหน่วยงานนำไป deploy เองในเครือข่ายที่ตนมีสิทธิ์ โปรดเปิด authorization gating ไว้เสมอ และสแกนเฉพาะทรัพย์สินที่ได้รับอนุญาต
